# instagram-videolar-kuranvefizik

Kur'an temalı kısa dikey videolar (Instagram Reels · TikTok · YouTube Shorts).

- **Format:** 4K dikey (2160×3840), 30 fps, H.264 + AAC
- **Ses:** seslendirme (müziksiz, belgesel havası), sosyal medya ses seviyesine normalize
- **Altyazı:** videoya gömülü; ayrıca düzenlenebilir `.srt` dosyaları `altyazilar/` klasöründe
- **Görsel dil:** sembolik anlatım — insan veya peygamber tasviri yok; anlatılan ayetler Arapça ve mealiyle ekranda
